# Support

Mango is a single-maintainer alpha. There is no household support SLA.

- Bugs and patches: GitHub issues and pull requests
- Security: [SECURITY.md](SECURITY.md)
- How to run it: [docs/INSTALL.md](docs/INSTALL.md) and [docs/OPERATIONS.md](docs/OPERATIONS.md)
- What is proven: [docs/STATUS.md](docs/STATUS.md)

Do not open issues that include API keys, OAuth tokens, debrid URLs, or
private playlists.
