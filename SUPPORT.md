# Support

Mango is a single-maintainer public alpha. There is no household support
SLA and no guaranteed response time.

| Need | Where |
|------|-------|
| How to install | [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) · [docs/INSTALL.md](docs/INSTALL.md) |
| How to watch | [docs/USER_GUIDE.md](docs/USER_GUIDE.md) |
| Something broke | [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md), then a GitHub issue |
| Security | [SECURITY.md](SECURITY.md) |
| What is proven | [docs/STATUS.md](docs/STATUS.md) |
| Product page | https://aaam.dev/mango/ |
| Email | support@aaam.dev with subject `mango` |

Do not open issues that include API keys, OAuth tokens, debrid URLs,
signed stream links, or private playlists.
