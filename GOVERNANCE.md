# Governance

Mango is a single-maintainer project under [aaam.dev](https://aaam.dev).
The repository owner reviews pull requests, cuts tags, and records
STATUS evidence.

There is no release train beyond `main` plus annotated alpha tags.
Breaking runtime contracts requires a STATUS note and a CHANGELOG entry.

Public wording is constrained by [docs/PUBLIC_CLAIMS.md](docs/PUBLIC_CLAIMS.md).
The locked pad map and mpv-only daily player are not RFCs; change them
only with an issue and maintainer approval.

Code of conduct: [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
